# codespaces

Manage GitHub Codespaces lifecycle via `gh codespace` CLI commands.

## What it does

Provides a quick reference and workflow recipes for creating, connecting to, debugging, and managing Codespaces — with a dedicated section for this repo's devcontainer setup.

## Triggers

- "create codespace", "ssh into codespace", "stop codespace"
- "codespace secrets", "codespace logs", "list codespaces"
- "delete codespace", "gh cs", "codespace machine types"

## Dependencies

- `gh` CLI with codespaces extension (included in gh)
- GitHub account with Codespaces access
