`/pr-review` is kept as a compatibility alias for `/respond-to-pr-review`.

Use `/respond-to-pr-review` when the task is to read review comments on our PR, reflect on them in context, decide **do / defer / decline**, and then execute the response plan.

Use `/review-pr` when the task is to review a PR someone else wrote.
