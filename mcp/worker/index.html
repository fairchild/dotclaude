Skills over MCP.

This site began as a reference implementation of the experimental Skills Over MCP project. That remains its starting point: give agents a straightforward way to discover and use skills.

We're extending the same library with readable pages, Markdown discovery, and verified downloads, so agents can use the access method that fits their tools.

About this library

Built from fairchild/dotclaude. Machine-bound skills ({{MACHINE_BOUND}}) are available only through the local server.

MCP usage metrics include method, skill, outcome, latency, response size, country, datacenter, user agent, and an optional client label. This service does not store IP addresses. Infrastructure: Cloudflare Workers; usage events: PostHog.
