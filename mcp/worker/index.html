MCP Skills Extension · SEP-2640 · io.modelcontextprotocol/skills

dotclaude skills, served over MCP

Every portable skill from fairchild/dotclaude — {{PORTABLE}} of {{TOTAL}} — as one resource per file under skill://, with complete per-skill manifests and SHA-256 digests, so a consuming host can verify every byte it reads.

POST https://skills.cloudcompute.com/mcp

Connect

From Claude Code or any MCP host. The x-skills-client header is optional — it labels your traffic in the usage metrics.

{
  "mcpServers": {
    "dotclaude-skills": {
      "type": "http",
      "url": "https://skills.cloudcompute.com/mcp",
      "headers": { "x-skills-client": "your-label" }
    }
  }
}

A host that knows the extension gets skills/list, skills/get, and resources/directory/read; a host that doesn't sees ordinary MCP resources and everything still works. Skills follow the Agent Skills spec; the transport is SEP-2640; the server is a public reference implementation.

What's served

{{SKILL_ROWS}}

Machine-bound skills ({{MACHINE_BOUND}}) are excluded from this hosted tier — they assume their author's machine and are served only by the repo's local stdio binding.

Transparency

Requests to this server are logged for operational and usage metrics: JSON-RPC method, skill name, outcome, latency, response size, country, datacenter, user agent, and the optional x-skills-client label. No IP addresses are stored by this service, anonymous requests are not individually tracked, and identification happens only if you label yourself. Don't put personal data in the label. Infrastructure: Cloudflare Workers; usage events: PostHog (US).
